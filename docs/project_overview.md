# Quadruped Robot Project

This project is a manually assembled quadruped robot built using:

- Arduino Uno
- 12 Servo Motors
- Servo Motor Driver
- Battery Pack
- Custom Chassis

The robot is capable of:

- Forward movement
- Backward movement
- Left turn
- Right turn
- Rotational movement

## My Contribution

I designed and assembled the entire hardware structure manually, including:

- Servo motor mounting
- Leg alignment
- Wiring
- Power distribution
- Mechanical balancing

# Future Vision

The long-term vision of this project is to develop an advanced autonomous robotic system capable of assisting in defense, rescue, and surveillance operations.

The quadruped robot is planned to communicate with aerial drone systems to receive real-time environmental data, location mapping, obstacle information, and navigation support. This coordinated robotic system can be useful for:

- Search and rescue missions
- Hazardous area inspection
- Remote surveillance
- Disaster response operations
- Navigation in difficult terrains
- Reducing human risk in dangerous environments

This project is inspired by the idea of contributing toward technological innovation for national safety, smart robotic systems, and future autonomous assistance technologies that could support organizations such as the Indian Army and emergency response teams.
