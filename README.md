# Quadruped Robot using Arduino Uno

## Project Overview

This is a 12-servo quadruped walking robot built using Arduino Uno.

The robot is capable of multiple movements including:

- Forward walking
- Backward walking
- Turning left
- Turning right
- Rotational movement

The entire hardware structure was manually assembled including servo mounting, balancing, chassis integration, and wiring.

---

# Hardware Components

| Component | Quantity |
|---|---|
| Arduino Uno | 1 |
| Servo Motors | 12 |
| Servo Driver | 1 |
| Battery Pack | 1 |
| Chassis Frame | 1 |
